# 2026-08-08 タイムスタンプ一括処理のプロダクト所有者指示

この文書は、Issue #1を補足するタイムスタンプ一括処理と公開承認の正本である。

- 運用者による1回の明示的なChatGPT／Codex要求は、その要求で指定した識別子または有限の選定条件から、今回処理する適格動画の有限集合を開始時に固定する。
- 固定した集合の各動画は、動画ごとの追加チャット承認を求めず、タイムスタンプ候補の作成、事実確認、編集確認、決定的検証を経て、1動画だけを対象とするPRのレビュー可能状態、または根拠を示した処理不能状態のいずれかまで処理する。
- ある動画が根拠不足、取得不能、確認不合格、決定的検証不合格その他の理由で処理不能になっても、集合内の残りの動画の処理を継続する。
- レビュー可能な動画は従来どおり1動画1PRとし、そのPRを人が確認してマージする操作を、当該動画を公開する最終承認とする。
- 人の明示要求がない予定実行、GitHub ActionsからのAI/API呼出し、従量課金API、自動マージ、自動公開、独自の公開Actionは使用しない。
- 固定した集合の全動画がPRレビュー可能または理由付き処理不能の終端結果へ到達した時点で、その一括処理は完了する。処理不能の動画は理由を残し、成功扱いや公開対象へ読み替えない。

出典: 2026-08-08のチャットで承認された、有限対象の一括タイムスタンプ処理、1動画1PR、人によるマージ承認、失敗分離、無人・有料・自動公開禁止の指示。
