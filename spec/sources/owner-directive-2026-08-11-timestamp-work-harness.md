# 2026-08-11 Work用タイムスタンプ自律ハーネスの所有者指示

この文書は、2026-08-08の有限一括処理指示を、ChatGPT Workから実行できる再開可能な運用ハーネスとして具体化する正本である。

- PythonでGoogle Sheetsの「対象動画」台帳を読み、作成済み・除外・既存PRを除いた適格対象を、行番号と行指紋を含む有限集合として開始時に固定する。
- 公開の作成者時刻一覧または日本語字幕を優先し、取得できない場合は公開音声と無償ローカル音声認識を用いる。チャットは必要な場合だけ匿名の補助信号として取得し、全編根拠や境界決定の代わりにしない。
- 章構成、事実確認、編集確認等の意味判断は、役割ごとに独立した非対話の`codex exec`で実行し、既存の決定的検証に合格しない結果を採用しない。
- 合格した各動画は、自動的に1動画ブランチをcommit・pushし、実在するdraft PRを作成してから、そのPR URLを公開承認gateとして正本候補へ記録する。
- 各動画の最終pushまたは理由付き処理不能をGoogle Sheetsへ反映し、更新直前の行指紋一致と更新後の再読で反映を確認する。競合行は上書きせず、その動画だけを理由付き処理不能にする。
- 中断後は同じbatch IDと固定集合から再開し、0件の場合は外部書込みをせず、全件がPR作成・push・台帳確認済みまたは理由付き処理不能になるまで継続する。
- この開始要求は、対象集合内の公開素材取得、Codex実行、branch、commit、push、draft PR、対応する台帳更新を許可するが、merge、公開、認証回避、課金API、非公開・メンバー限定動画の取得を許可しない。

出典: 2026-08-11のチャットで承認された、Pythonによる台帳確認、素材取得、`codex exec`判断、commit・push・PR、台帳更新を完了まで自律実行し、今後ChatGPT Workから利用する指示。
