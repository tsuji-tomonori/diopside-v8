# 動画長Slider操作中のタグ欄安定化

- 指示日: 2026-08-25
- 権限者: repository owner
- 対象: 公開検索画面の動画長Sliderとタグ絞り込み

動画長Sliderを連続操作している間は、動画長に応じたタグ候補の絞り込みと件数更新を行わず、タグ欄と画面全体の縦方向の長さを維持する。Sliderのつまみと現在値は操作に追従して即時更新し、最後のSlider入力から約100ミリ秒経過した時点で、最新の動画長を使ってタグ候補と件数を一度だけ更新する。

動画検索結果そのものは、既存どおり「絞り込みを反映」した条件を用いる。タグ選択、公開日、検索語によるタグ候補の更新挙動と、既存URLの条件表現は変更しない。
