# ゲーム作品単位のジャンル正本と探索導線

- 指示日: 2026-08-28
- 指示者: repository owner
- 対象: diopside v8 のゲーム作品分類、公開タグ、ゲーム探索画面

## 永続化する結果

1. ゲームジャンルは動画ごとに独立判定せず、ゲーム作品を単位とする正本から公開動画へ一貫して反映する。
2. 作品のジャンルは Steam、公式ストア、開発元または発売元の公式ページを根拠に確認し、根拠 URL と確認日を保持する。
3. 同じゲーム作品を扱うすべての公開動画は、同じゲームジャンル集合を持つ。
4. ゲームジャンルから、そのジャンルでプレイしたゲーム作品の一覧へ移動できる。
5. ゲーム作品から、その作品をプレイした公開動画の一覧へ移動できる。
6. 企画名、ハッシュタグ、一般名など単一ゲーム作品ではない既存の誤分類は、ゲーム作品一覧に表示しない。

## 今回確認した代表例

- `B6D1F1PMMHw` を含む『ワガママハイスペック』は「アクション」ではない。
- Steam は同作を `Adventure, Casual` とし、ストアの利用者タグでは Visual Novel が主要分類になっている。
- コンシューマ版公式サイトは同作を「恋愛アドベンチャー」としている。
- diopside の公開分類は「アドベンチャー」「カジュアル」「ビジュアルノベル」とする。

## 追加確認（同日フォローアップ）

1. 既存のゲームジャンル語彙だけへ無理に当てはめず、公式ストアの形式ジャンルまたは上位人気タグで反復確認できる不足分類を追加する。
2. 新しい分類は、確認元があること、既存分類ではプレイ性が失われること、複数作品を探す再利用可能な軸であること、テーマ・販売形態・単発の仕掛けではないことをすべて満たす場合だけ追加する。
3. 複合ジャンルを既存タグの組合せで表せる場合は新語を増やさない。たとえばサバイバルホラーは「サバイバル」「ホラー」、アクションアドベンチャーは「アクション」「アドベンチャー」とする。
4. Steam確認元166作品と公式ストア・公式サイト等の確認元78作品をゲーム単位で再確認し、新たに「カジュアル」「プラットフォーマー」「サバイバル」「ステルス」「ローグライク」「ウォーキングシミュレーター」を採用する。
5. 表記違いが同じゲームを指す場合は一つのゲーム単位へ統合し、すべての表記から同じジャンルと全対象配信へ到達できるようにする。
