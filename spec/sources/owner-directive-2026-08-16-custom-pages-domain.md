# 所有者指示: GitHub Pages の独自ドメイン

- 日付: 2026-08-15
- 根拠: 所有者が `tme.page.diopside.net` のCNAMEとGitHub Pages設定を確認し、同ドメインでの公開を指示した。
- 永続制約: Pagesは引き続き公開リポジトリの `main/docs` branch方式で配信する。独自ドメインを使う場合、`operations/pages-policy.json` の許可値と `docs/CNAME` は完全一致させる。追加の公開実行時サービス、独自Pages deploy Action、有料のGitHubプランを導入しない。
