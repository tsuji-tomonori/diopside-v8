# 歌唱楽曲一覧と楽曲タグの所有者指示

- 受領日: 2026-08-25
- 受領元: ChatGPT Work でのリポジトリ所有者依頼
- 対象: diopside v8

## 指示

1. 配信内で歌った曲と「歌ってみた」の楽曲一覧を表示する。
2. 各実績から対象動画へ移動でき、配信の場合は該当開始秒を開く。
3. 主または副ジャンル「歌」を押すと楽曲一覧へ移動する。
4. 各楽曲に原曲へのリンクを付ける。
5. 歌枠でない通常配信中の歌唱や鼻歌も、対象場面として記録できるようにする。
6. 確認済みの楽曲は動画の楽曲タグとしても検索できるようにする。

## 解釈境界

- 楽曲名、白雪巴本人の参加、開始秒を公開資料から確認できない場合は掲載しない。
- 鼻歌は場面の範囲を明確にするため、開始秒と終了秒の両方を記録する。
- 公開データには楽曲、原曲、対象動画、種別、開始・終了秒だけを出力し、内部の根拠参照は公開しない。
