# 詳細絞り込みの移動量と操作回数の削減

- 指示日: 2026-08-28
- 権限者: repository owner
- 対象: 公開検索画面のタグ・公開日・動画長による詳細絞り込み

詳細絞り込みでは、タグ数の増加によって公開日や動画長へ到達するまでのスクロールが長くならないようにする。公開日と動画長は、全タグ一覧を通過せずに操作できる位置へ置く。

タグは常に全件を展開せず、選択中のタグ、よく使う主ジャンル、タグ名または別名による入力を短い導線として提供する。全タグを見て選ぶ場合は大分類と小分類ごとに折り畳み、利用者が必要な分類だけを開けるようにする。タグの追加・解除だけで検索へ反映して動画一覧へ戻る既存動作、候補件数、0件候補の非表示、複数タグのAND条件は維持する。
