# 公開日範囲Pickerと動画長Slider

- 指示日: 2026-08-25
- 権限者: repository owner
- 対象: 公開検索画面の詳細絞り込み
- 参考UI: https://www.inspora.design/posts/1-30

公開日の開始日と終了日は、二つの日付欄を常時並べるのではなく、一つの日付範囲Pickerで選択できるようにする。Pickerでは開始日と終了日、両端を含む期間を一続きに確認でき、カレンダー上の二日選択、開始日・終了日の直接指定、代表的な期間のクイック選択、指定解除を提供する。

動画長の最小値と最大値は、二つのつまみを持つSliderで分単位に選択できるようにする。既存の動画長区分はクイック選択として維持し、選択した区分の境界をSliderへ反映する。Sliderはポインター、タッチ、キーボードで操作でき、つまみが交差しないようにする。既存URLの条件表現と逆転範囲の日本語エラーは維持する。
