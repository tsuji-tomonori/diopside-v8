## 改訂方針（2026-08-02）

本Issueを、次の決定に基づく `diopside-v8` の要件ベースライン候補へ改訂する。

1. ChatGPT／Codexは運用者が必要なときに画面から起動する。GitHub ActionsからChatGPT／Codexを呼び出さず、日次の無人実行も行わない。
2. サービス運用に起因する請求額は、既存のChatGPT／Codex契約を除いて月額0円とする。

4. タグは文字検索とは分離した補助的な絞り込みとして表示する。タグは完全一致で判定し、複数選択時は選んだタグをすべて含む動画だけを表示する。

## 運用の流れ

1. 運用者が必要な時期にChatGPT／Codexを明示的に起動する。
2. ChatGPT／Codexが、公開情報とリポジトリの正本データを照合し、新規または更新された動画を候補として示す。
3. ChatGPT／Codexが、リポジトリ内のスキルと決定的スクリプトを用いて、タグ、タイムスタンプ、ワードクラウドの候補を作る。
4. 決定的スクリプトが、構造、タグ体系、時刻範囲、重複、公開禁止情報、検索索引、静的成果物を検証する。
5. 検証合格時だけ、動画1件につき1件のプルリクエストを作成する。
6. 人が動画と候補を確認し、修正、差戻し、承認、マージのいずれかを行う。
7. マージされた `main/docs` の静的成果物を、GitHub Pagesのブランチ公開機能が配信する。
8. 誤りがあれば、該当変更の取り消しまたは修正プルリクエストで直前の正しい状態へ戻す。

ChatGPT／Codexを起動するGitHub Actionsは作成しない。リポジトリ独自の予定実行・生成・公開用Actionsにも依存しない。GitHub Pagesは `main` ブランチの `/docs` を公開元とし、ビルド済みの静的成果物をプルリクエストに含める。

### GitHub Pagesに関する前提

- 2026-08-02時点で本リポジトリは公開設定である。
- GitHub公式文書では、公開リポジトリのGitHub FreeでPagesを利用できる。
- GitHub公式文書では、ブランチのルートまたは `/docs` を公開元に指定できる。
- ブランチ公開でもGitHub側のPages構築・配信処理が履歴へ表示される場合があるが、リポジトリからChatGPT／Codexを起動する独自Actionsではない。本Issueが禁止するのは、ChatGPT／Codex呼出し、予定実行、候補生成、検証、静的成果物生成、公開を行うリポジトリ独自Actionsである。

#### E-2. タイムスタンプの基準

タイムスタンプは、短い名場面を集める「見どころ」ではなく、動画全体を目的の場面まで移動するための目次とする。章数は経過時間から機械的に決めず、次の内容境界を用いる。

| 主ジャンル | 主な境界 | 公開名で避ける内容 |
|---|---|---|
| ゲーム | ゲーム開始、試合、ステージ、主要目的、終了後の感想 | 死亡、犯人、秘密の正体、最終ボス名、結末 |
| 企画 | 説明、参加者、コーナー、休憩、結果、告知 | 単発の冗談や短い反応 |
| 雑談 | 継続する話題の転換、投稿テーマ、告知、スパチャ読み | 一つ一つのコメント返信 |
| ASMR | 道具、左右、施術、シチュエーションの切替 | 短い音や反応ごとの分割 |
| 歌 | 各曲、独立したMC、告知 | 一時的な曲間発言の過分割 |
| 朗読・声劇 | 作品、幕、場面、出演者の切替 | 展開、真相、解決 |
| 同時視聴 | 同期、話数・部、休憩、終了、感想 | 物語上の出来事 |
| TRPG | 導入、中立的な幕・場面、休憩、感想 | 秘密、正体、判定結果、結末 |

ここでいう重大指摘は、対象経路の不適合、新規生成における全編根拠不足、根拠のない境界、根拠にない章名、公開名のネタバレ、過分割、分割不足、または形式違反を指す。

## 検索の受入例

検索実装時は、少なくとも次を固定評価データへ含める。実在タイトルを用いた最終データは、個人名・作品名・公式表記を確認して別の検索品質資料に版管理する。

| 観点 | 検索語とタイトルの関係 | 期待 |
|---|---|---|
| 完全一致 | 正規化後にタイトル全体と一致 | 1位 |
| 部分一致 | タイトルの途中に検索語がある | あいまい一致より上位 |
| かな表記 | ひらがなとカタカナだけが異なる | 一致 |
| 全角・半角 | 数字、英字、空白の幅だけが異なる | 一致 |
| 脱字 | 3文字以上の語から1文字欠ける | 許容距離内なら一致 |
| 余字 | 3文字以上の語へ1文字多く入る | 許容距離内なら一致 |
| 誤字 | 3文字以上の語で1文字が異なる | 許容距離内なら一致 |
| 入替 | 隣接2文字の順序だけが逆 | 許容距離内なら一致 |
| 短すぎる語 | 1～2文字 | 部分一致だけ。あいまい検索なし |
| 複数語 | 空白区切りの2語 | 両方がタイトルにある場合だけ一致 |
| タグだけの語 | タグにだけ存在 | 文字検索では不一致。タグ選択時だけ一致 |
| ワードクラウドだけの語 | ワードクラウドにだけ存在 | 文字検索では不一致 |
