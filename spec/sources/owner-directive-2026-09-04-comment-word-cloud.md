# コメントの熱量を伝えるワードクラウド

- ワードクラウドは、対象動画の公開コメントまたは公開チャットリプレイを利用できる場合、視聴者が強く反応した話題を優先して表す。
- 大きい語と小さい語の差を明確にし、横書きと縦書きを混ぜ、表示面を埋める密集配置にする。横一列の語句一覧や、余白が大きく熱量を感じにくい配置にしない。
- 同じ語句、重要度、画面幅、描画規則からは同じ配置を再現する。
- 公開コメントまたは公開チャットを取得できない場合は、公開字幕、公開概要欄、または運用者が明示的に提供した公開本文を代替入力にできる。ただし、実際の入力種別を画面に明示し、コメント由来と偽らない。
- 生のコメント、チャット、投稿者名、投稿者IDは一時処理に限り、Git、プルリクエスト、確認報告、Pagesへ保存しない。正規化した語句、重要度、入力指紋、規則版だけを人が確認して公開する。

表示参考: 2026-09-04に利用者が添付した、大小の語を縦横に混ぜて面全体へ密集配置したワードクラウド画像。

出典: 2026-09-04のチャット指示「コメントをベースにこんな感じで表示するようにしてほしい。今だと横一覧だしスカスカだしで、対象動画への熱量が足りない」。
