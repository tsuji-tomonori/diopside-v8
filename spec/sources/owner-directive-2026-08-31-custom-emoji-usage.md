# 動画別カスタム絵文字集計・比率表示

- 公開チャットリプレイを取得できる動画では、通常のUnicode絵文字と区別してカスタム絵文字の全出現回数を種類別に集計する。
- 集計済み動画の詳細では、全カスタム絵文字について使用回数と、カスタム絵文字総使用回数に占める比率を比較できるチャートを表示する。
- 公開正本には匿名化した絵文字ID、公開ショートコード、回数、総数、入力指紋、規則版、更新日時だけを保持し、生チャット、本文、投稿者識別子、元の絵文字IDを保存しない。
- 先行導入は `UZcmZzKQWYc`、`4zN7YiSw06c`、`BZkCPMIsz1k` の3動画とする。

出典: 2026-08-31のチャット指示「チャット欄のカスタム絵文字について動画ごとにすべてカウントしたうえで、その比率を動画ごとに見られるようにしたい。チャートでいい感じに見たい。まずいくつかの動画で先行で試して入れてみて」。
