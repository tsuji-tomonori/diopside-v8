# Genre rules

| 主ジャンル | 境界として優先 | 公開名で避けるもの |
|---|---|---|
| ゲーム | 開始、試合、ステージ、主要目標、エンディング、感想 | 死亡、犯人、秘密、正体、最終ボス、結末 |
| 企画 | 説明、コーナー、出演者、休憩、結果、告知 | 単発の冗談・反応 |
| 雑談 | 継続する大きな話題、投稿テーマ、告知、スパチャ読み | 個々の短い逸話・返信 |
| ASMR | 道具、左右、施術、シチュエーション | 短い音・反応ごとの分割 |
| 歌 | 各曲、継続するMC、告知 | 短い発話ごとの分割 |
| 朗読・声劇 | 作品、幕、場面、出演者 | 展開、秘密、結末 |
| 同時視聴 | 同期、本編・話数、休憩、終了、感想 | 物語上の出来事 |
| TRPG | 導入、中立な幕・場面、休憩、感想 | 秘密、正体、判定、結果 |

2時間で6–15章は観測上の目安であり要件ではない。時間経過や固定件数ではなく、移動目的が変わるときだけ境界を置く。冒頭待機と末尾無音を独立章にしない。

## ゲストが順番に登場する企画

各ゲストの紹介・通話開始を移動先として扱い、章名にはその人物の正規名を入れる。「最初の参加者」「育成インタビュー」やゲーム内キャラクター名だけで終えない。白雪巴を紹介する区間と本人が通話に入る区間が異なるなら、根拠のある開始位置を分ける（例: 「白雪巴のマルゼンスキー紹介」「白雪巴が通話に登場・育成インタビュー」）。他のゲストも同じ基準で扱う。

投稿・アンケート・推薦品の読上げは「白雪巴の投稿紹介」などとし、本人が出演・通話したと推測しない。匿名として公開された投稿の人物を推定・公開しない。順番やコメントだけから人物と時刻を割り当てず、字幕の前後文脈・音声・画面または作成者一覧で確認する。既存更新で根拠が不足する箇所は既存時刻を維持して具体的な再確認理由を残す。

氏名が入口の字幕にない場合は、同じ通話の自己紹介・呼びかけ・退出まで追って照合する。通話の連続性が確認できれば、後から明示された氏名を実際の入口へ対応させてよい。発話者が自分の同期や過去のゲストを話題にしただけの言及、過去形の振り返りを新たな入室と扱わない。前後編で共通の概要欄は動画ごとの出演確認を代替しない。

声真似などで匿名参加が明示されている場合は「匿名参加者の○○の声真似」のように公開範囲で区別し、本人の正規名を補完しない。公開匿名と字幕欠損による未確認は区別する。同時に入る複数人は同じ章に併記し、録画メッセージ・投稿紹介・実通話を分ける。
