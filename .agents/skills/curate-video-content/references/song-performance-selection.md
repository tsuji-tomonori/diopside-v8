# 歌一覧の本人参加判定

要件は `spec/sources/owner-directive-2026-08-25-song-performance-index.md` と要件正本 V8-TAG-037/038、V8-DISPLAY-015 に従う。登録先は `content/songs/song-performances.json`。

- 他チャンネルの誕生日・3Dライブ・お披露目・企画でも、曲名、白雪巴の歌唱参加、開始秒を曲単位で確認できれば掲載する。ソロに限らずデュエット・合唱も含む。
- 動画に本人が出演すること、人物タグ、概要欄のゲスト一覧だけでは、その動画の全曲を本人歌唱にしない。トーク、審査員、ダンサー、伴奏、BGM、他の出演者だけの曲は歌唱実績の根拠にならない。
- 歌唱者を明記した承認済みタイムスタンプ、作成者のセットリスト、本人・主催者の曲単位の公式表記を照合する。曲名だけ・直後に本人とのトークがあるだけでは本人参加の唯一の根拠にしない。
- 歌唱のある企画を掲載するためだけに動画全体へ歌枠タグを付けない。歌枠でない場面は既存の `配信内歌唱` を使う。
- `spec/sources/guest-song-performance-audit-v1.json` に曲ごとの歌唱者、確認理由、出典、開始秒と時刻IDを記録する。未確定の曲を推測登録せず、足りない根拠を `要確認` の理由へ記載する。要確認は歌唱なしを意味しない。
- 選定済み動画で別の本人歌唱曲が判明したら、根拠を追加して選定表と楽曲正本を一緒に更新する。通常動画の時刻一覧の再生成は別の動画PRで扱う。
- `npm run audit:guest-song-performances` と `npm run audit:song-frame-performances` を実行する。候補検出は探索漏れ防止であり掲載判定ではない。監査表の選定外の実績、時刻ずれ、掲載漏れは修正する。
